## Jobs-to-be-Done (JTBD)

### Scheduling a Clinical Review (Supervisor)
When building a weekly schedule, I want to quickly assign reviewers to DAR/CPOE/new incoming/cross-training with clear rules and feedback, so I can ensure coverage without conflicts and publish confidently.

### Managing Reviews (Supervisor)
When updating assignments mid-week, I want to find the right schedule and edit with minimal friction, so I can shift coverage based on demand while avoiding errors.

### Reviewer Experience (Clinician)
When checking my assignments, I want a clear, mobile-friendly view of where I’m assigned and when, so I can plan my availability and confirm or decline requests promptly.

### Authentication & Access
When logging in, I want a consistent, reliable sign-in and session handling, so I can access assignments without unexpected logouts or confusing redirects.

## Current Solution & Pain Points
- Assignment grid is powerful but dense; DAR cell “X” is unclear; blocked states need clearer explanations.
- Action hierarchy in header is flat; Save/Publish compete with secondary actions.
- Reviewer availability and accept/decline are missing; clinicians are view-only.
- Auth mismatch with prompt (Azure AD vs Firebase) introduces ambiguity; session expiry UX is minimal.
